# 品牌视觉方向（待审核）

> 本文档描述**多多认为什么是美丽**，不是某一款产品的配色卡。
> 任何替多多做视觉的 AI，应先读本文，再动手。读完应能在脑中"长出"多多的眼睛。
> 状态：**待多多审核**。审核通过后，本文件即成为正式审美标准，Design Skill 的 brand-dna 与之对齐。

---

## 一、核心理念：美丽对多多不是装饰

多多把"美"当作一件严肃的事，它承担五种功能：

1. **身份表达** —— 我是什么人，靠审美说出来。
2. **情绪调节** —— 看见美，人能喘口气。
3. **生活世界构建** —— 美不是点缀，是搭一个值得活的世界。
4. **品牌识别** —— 一眼就知道"这是多多的"。
5. **对抗麻木和庸常** —— 这是底线。丑的、模板的、AI 味的，都是庸常，都要被挡在外面。

→ 推论：**AI 做视觉时，第一目标不是"好看"，是"像多多、有温度、不像通用模板"**。约束 AI 的自由度，才能保证输出质量。

---

## 二、审美世界观：多多被什么吸引

从精选 pin 反推，多多持续被这几类世界吸引（按出现强度排序）：

- **海岸与海洋**（最强底色）：海螺、贝壳、星鱼、海平线、冲浪板、蓝绳、绿松石。不是"度假照"，是**带手作感的海洋原始感**。
- **波西米亚 / 游牧**：叠戴的项链与串珠、佩斯利花纹、流苏、多层吊坠、旅行地图墙。关键词是**自由、层叠、不整齐才对**。
- **部落 / 原始**：图腾石雕、原始箭头符号、单线松树山脉太阳、民族图案边凳。是**有力量、有方向感、去文明的野**。
- **手作温度**：麻绳、原木、纸标签、手写、编织、做旧。所有东西看起来都**被人手碰过**。
- **侘寂 / 极简力量**：素色衣橱、单线刺青、半圆海平线。留白、克制、但**有骨头**（力量感来自极简里的方向）。
- **复古暖调**：红棕植物几何纹样、爱迪生灯泡、复古世界地图。不是做旧滤镜，是**时间的厚度**。
- **线描插画**：十二星座女性、花卉卷草、几何纹样。幽默、原始、女性主义、手绘不完美。

一句话概括多多的审美 DNA：**野而温柔、原始而精致、自由而有骨头、手作而有世界。**

## 二·五、纹身 / 灵性符号 / 部落 —— 一条被低估的强轴

回头看精选 pin，**纹身手稿、灵性符号、部落原始图腾** 是独立且极强的一条线（grep 命中 80+ 张）。之前我把它压在"部落/原始"里轻描淡写，这是遗漏。它不该只当装饰，而是多多的**意义系统**——符号承载身份、信念与力量，不是噪点。

从 pin 反推，这条线有四个子世界：

- **A. 灵性符号（spiritual symbols）**：太阳/月亮/星辰、曼陀罗、神圣女性、阴阳眼、三叉戟、莲花、螺旋、护身符/塔罗、柏柏尔符号（Berber）、萨满图腾。气质：神秘、对称、有仪式感——但避免"星座运势"式的俗艳，符号要有分量。
- **B. 部落 / 原始（tribal / primitive）**：岩画涂鸦（太阳/星星/举手人形/蜗牛/螺旋）、点刺（dotwork）技法、几何部落图腾（对称人面/波浪/栅栏）、箭头/羽毛、编织绳结、科科佩利（Kokopelli）岩刻。气质：古老、手工、原始；用牛皮纸/米底增强仪式感。
- **C. 单线融合（single-line fusion）**：女人 × 动物（狮子/狼/豹/鸟/兔）连续一笔线条、圆形框架、留白极多。代表"女性内在力量"。参考母题：闭眼女人与咆哮狮子、女人与狼圆形融合。
- **D. 自然（贯穿全品牌）**：海浪、山、棕榈、贝壳、植物藤蔓、佩斯利——作为背景晕染与线描点缀。

**调用规则**（已写入 Design Skill 的 `brand-dna.md`）：每个画面/分区至少 1 个明确母题；母题一律线描、单色、与底色克制对比；灵性符号要有"意义"、不在站内随机撒点；可从 `assets/motifs.svg` 取太阳/月亮/海浪/螺旋/曼陀罗/女人×狮/科科佩利/羽毛/柏柏尔符号/箭头。

## 三、色彩世界（从 pin 提炼，非凭空）

基色永远是**暖的、自然的、带海的**：

| 角色 | 色值 | 来自哪 |
|---|---|---|
| 米白麻（底） | `#F1E9DA` | 侘寂衣橱、麻绳、纸 |
| 原木棕 | `#8A6A4A` | 原木衣架、树桩边凳 |
| 陶土赭 | `#B5713F` | 红棕纹样、佩斯利、波西米亚 |
| 海洋蓝绿（主） | `#157A6E` | 海螺、绿松石、海 |
| 绿松石（亮） | `#4FB0A1` | 绿松石手绳、海洋生物 |
| 深墨绿（墨） | `#1F2E29` | 线描深蓝、夜海、文字 |
| 做旧金 | `#C99A3F` | 金吊坠、太阳人脸、图腾 |
| 佩斯利红（点） | `#9E4A3A` | 佩斯利裙、红蓝织珠 |

**比例感**：大面积永远是米白麻 + 原木；蓝绿与陶土是中坚；金与红是**小面积点睛**，不能铺满。
**禁止**：纯正蓝、荧光、高饱和品红紫、纯黑大底、蓝紫渐变、玻璃拟态。

## 四、材质与肌理（多多靠"摸得到"判断美）

多多审美里**材质权重极高**，纯矢量扁平会失职：

- 必出现：麻、原木、贝壳、绳编、纸（带纹）、陶、做旧金属、植物。
- 技法：纸纹 / 编织纹 grain（opacity ≤ 12%）、晕染（radial/linear gradient 柔化，禁止硬边拼接）、手绘不规则边缘。
- 图片基调：自然光、低饱和、有温度、带原始感；拒绝高对比商业大片。

## 五、形态与构图

- **有机不规则**：圆角要"手作感"，不要完美几何；允许波浪形、撕边、手绘边代替直线。
- **层叠不整齐**：项链叠戴、吊坠多层、串珠流苏——"整齐"在这里是缺点。鼓励错落、叠压、拼贴。
- **极简里有骨头**：单线、留白、克制，但必须有方向或力量（如松树山脉太阳的竖向力）。
- **母题驱动**：每个画面至少放一个下面的母题，鼓励叠加。

## 七、字体与文字气质

- 已锁方案 **B（全衬线书卷）**：中文思源宋体 / Noto Serif SC，西文 Fraunces（italic 做强调）。
- 理由：与"书卷、手作、复古、线描"高度同构；拒绝 Inter / Roboto 等冷感无衬线。
- 文字要有"手写感"的余地：允许 italic、允许轻微不规则排布、允许大装饰数字 / 英文做节奏。

---

## 八、禁忌清单（AI 绝对不做）

- 冷淡的通用模板感（"又是 AI 做的"）。
- 荧光色、纯正蓝、蓝紫渐变、玻璃拟态、纯黑大底。
- 所有 section 居中、强制对称网格、死板对齐。
- 任何 HTML 默认样式（引用块/列表/表格/卡片必须来自组件库）。
- 硬阴影、bounce 动画、过度平滑的"科技感"。
- 没有手作温度、没有自然材质、没有母题的"干净设计"。

---

## 九、应用场景（本方向如何落地）

- 官网 / 品牌主页：海岸 + 部落 + 侘寂的混合，留白充足。
- 产品图（首饰/手作）：麻绳原木底 + 自然光 + 叠戴层叠。
- 社媒 / 小红书卡片：线描插画 + 佩斯利 + 手写标签感。
- 纹身 / Logo / 灵性符号：单线（女人×狮、女人与狼）、曼陀罗、部落图腾、柏柏尔符号、点刺技法——作为"意义系统"而非装饰噪点；神秘但不玄虚。
- 包装：牛皮纸 + 麻绳 + 手写标签 + 复古纹样。

## 十、AI 使用守则（每次做视觉前）

1. 先读本文件，从上方取色彩与母题，**不得引入文件外颜色/字体**。
2. 至少融入 1 个母题（海浪/贝壳/部落/麻绳/地图…），鼓励叠加。
3. 保持手作温度与自然材质；留白但允许错落叠压。
4. 字体锁 B（全衬线）；禁止冷感无衬线与禁忌清单。
5. 输出前自检：颜色在不在世界里？有没有"野而温柔"？截图发朋友圈会不会被说"又是 AI 做的"？
6. 与本文冲突时，先问多多，不自由发挥。
