# QA & Acceptance Checklist｜验收清单

## P0：必须全过

### 战略与结构

- [ ] 首页海面只有四座岛：Stories / Work / About / Surf
- [ ] 另有一个可独立访问的 `/ai` 页面：AI / DUODUO OS
- [ ] AI 页面不是第五座岛，但不是可省略的 overlay
- [ ] 首页能在五秒内理解四个入口
- [ ] 核心命题与主句准确出现
- [ ] Logo 使用第一组官方 lockup，不是重新打字

### 视觉

- [ ] 主高亮为 `#00B4C5`，优先出现在少量被强调的字体/词语与链接上，而非大面积背景
- [ ] 主底为温暖米色
- [ ] Logo 蓝只用于身份识别，不大面积铺满
- [ ] 无蓝紫渐变、玻璃拟态、霓虹、廉价 SaaS 视觉
- [ ] 真实照片与素材优先，无 AI stock photo
- [ ] 每页有明确主空间语言
- [ ] 截图能被识别为 DUODUO，而不是通用 AI 模板

### 内容

- [ ] 完成与实验状态区分清楚
- [ ] 不伪造结果、客户或收入
- [ ] 不公开私人 Context、心理和关系资料
- [ ] Work 有明确 My Role
- [ ] Contact 与合作方式可用

### 双语

- [ ] 导航中英文
- [ ] 首页核心文案中英文
- [ ] 长正文可切换，不机械并排
- [ ] 中文和英文都经过语气检查
- [ ] URL 或状态能保留语言

### 交互

- [ ] 鼠标、键盘、触屏都可使用
- [ ] 不依赖 hover 才能进入页面
- [ ] `prefers-reduced-motion` 有 fallback
- [ ] 动效不阻碍内容出现
- [ ] 音频默认关闭
- [ ] Loading、Error、Empty 状态完整

### 响应式

- [ ] 手机首页不是缩小地图
- [ ] 四岛在手机上仍清楚
- [ ] About 时间线改为纵向
- [ ] Stories 物件可触屏操作
- [ ] Work 筛选器不横向溢出
- [ ] OS 在手机上可关闭、可返回

### 技术

- [ ] API Key 不在前端
- [ ] Notion 只取 Public 内容
- [ ] AI 只读公开知识库
- [ ] 404 / 500 页面存在
- [ ] sitemap、meta、OG、favicon 存在
- [ ] 图片和视频优化

## P1：应当完成

- [ ] 首页有一个真正令人记住的互动细节
- [ ] 每个岛 Hover / Focus 有微预览
- [ ] Stories 至少 6 个真实条目
- [ ] Work 至少 4 个完整案例或可信案例占位
- [ ] About 至少 7 节点与照片占位
- [ ] Surf 有真实 V1 内容，不是空页面
- [ ] Now 数据可更新
- [ ] Take Something 至少 3 个可用工具
- [ ] 关键事件有 Analytics

## P2：加分

- [ ] 用户可在海面留下短暂航迹
- [ ] Pen 作为极克制彩蛋出现
- [ ] Story 物件有正反面或来源记录
- [ ] About 航线可按地点或年份切换
- [ ] AI 回答能精准链接页面
- [ ] 分享卡因页面不同使用不同母题

## 最终人工检查

1. 这像多多吗？
2. 它是一个网站，还是一个只有设计师自己懂的艺术装置？
3. 商业合作方能否在两分钟内找到案例与联系方式？
4. 访客是否明白旅行、冲浪、青旅、AI 与泳衣为什么属于同一个人？
5. 动效关闭后，网站是否仍完整成立？
6. 有没有任何部分看起来“AI 很努力地做设计”？有则重做。

- [ ] 没有把亮蓝绿色铺满页面；正文仍以暖墨色为主
