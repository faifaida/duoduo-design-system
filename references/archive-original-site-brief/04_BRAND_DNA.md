# DUODUO Website Brand DNA

## 1. 核心审美命题

美不是装饰，而是：

- 身份表达
- 情绪调节
- 生活世界构建
- 品牌识别
- 对抗麻木、庸常与通用 AI 模板

设计第一目标不是“漂亮”，而是：

> **像多多、有温度、能摸得到、有真实生活留下的痕迹。**

## 2. 审美 DNA

**野而温柔、原始而精致、自由而有骨头、手作而有世界。**

主要视觉世界：

- 海岸与海洋
- 波西米亚与游牧
- 部落、图腾与原始符号
- 手作与自然材料
- 侘寂与留白
- 复古暖调
- 线描插画
- 真实照片与田野档案

## 3. 色彩 Token

### 核心色

| Token | 色值 | 用途 |
|---|---:|---|
| `--ocean-teal` | `#00B4C5` | 亮蓝绿色高亮。优先用于被强调的字体/词语，其次用于链接、选中态、航线节点和小面积互动反馈 |
| `--linen` | `#F1E9DA` | 主要米色底、纸张、陆地、内容背景 |
| `--logo-blue` | `#2E27A8` | 官方 Logo 与身份印章，不能替代成其他蓝 |
| `--warm-ink` | `#5B2E2B` | 中文标题、叙事文字、暖深色 |
| `--deep-sea-ink` | `#1F2E29` | 深色面板、夜海、功能层 |

### 扩展色

| Token | 色值 | 用途 |
|---|---:|---|
| `--paper` | `#FAF6EE` | 更浅的纸面、内容卡 |
| `--wood` | `#8A6A4A` | 木、行李箱、旧标签 |
| `--terracotta` | `#B5713F` | 陶土、手作、次要强调 |
| `--turquoise-soft` | `#4FB0A1` | 柔和海绿、非核心互动 |
| `--ocean-deep` | `#157A6E` | 深海绿、按钮和 hover 深态 |
| `--vintage-gold` | `#C99A3F` | 很小的星芒、指南针和金属细节 |
| `--paisley-red` | `#9E4A3A` | 极少量印章与点睛 |

### 比例原则

不使用僵硬的 60/30/10。

- 海洋影像 + 米色空间：主视觉主体
- 蓝绿色：约 6–10%，以字体高亮和细小交互标记为主，负责互动与生命力
- Logo 蓝：约 2–5%，只负责身份识别
- 陶土、金、红：总计不超过 8%，仅点睛

### 高亮色使用规则（已确认）

`assets/color-reference-teal-beige.png` 是用户确认的亮蓝绿色与米色感觉参考。不要把参考图的整套版式复制进网站。

亮蓝绿色的优先级：

1. **文字高亮**：大标题中的 1–3 个关键词、重要短句、链接文字、选中标签、状态词和数字。
2. **编辑性标记**：手绘下划线、荧光笔式文字底、文字选中态、脚注编号。
3. **小面积交互**：hover 线、focus ring、航线节点、地图定位点、active tab。
4. **极少量实心组件**：只在必要 CTA 或 Surf 页面局部使用。

不得：

- 把亮蓝绿色作为整页纯色背景；
- 把所有标题或全部链接都变亮蓝；
- 大面积铺在卡片、导航栏和内容区；
- 做成 neon/cyan 科技感。

简化理解：**亮蓝绿色是一支高亮笔，不是一桶墙漆。**

## 4. 字体

### Logo

Logo 字体属于官方字标的一部分。必须使用图片或矢量文件，不得以类似字体重新打出 `DUODUO WEAR` 作为正式 Logo。

### 页面字体建议

- 英文大标题：`Fraunces` 或同气质高品质衬线体
- 中文标题与正文：`Noto Serif SC / 思源宋体`
- 英文手写标注：`Caveat` 或更克制的手写字体
- DUODUO OS 终端：`Fira Code`，仅功能场景使用

禁止把 Inter、Roboto、Arial 作为主要视觉字体。

### 排版特征

- 大标题大，小注释小，形成明确层级
- 中文不使用过松字距
- 英文标签可全大写，但不能每句话都全大写
- 允许手写、斜体、印章文字和不规则标注
- 长文章确保阅读舒适，不因追求复古牺牲可读性

## 5. 材质

必须让人感到“被人手碰过”：

- 米色纸张与轻微纤维纹
- 麻布、绳结、编织
- 原木、皮革行李箱
- 贝壳、石头、陶器
- 做旧金属、旅行标签
- 真实照片、胶片边缘、票据与笔记

纹理透明度应克制，一般不超过 10–12%。

## 6. 母题

每页至少一个有意义母题，不能随机撒图标：

- 海浪 / 海平线
- 太阳 / 星芒
- 贝壳 / 海螺
- 航线 / 罗盘
- 部落图腾 / 岩画符号
- 绳结
- 世界地图 / 手写标签
- 螺旋
- 山、植物与自然线描
- 女性与动物的单线融合

Logo 图腾本身是最高级母题，可作为地图印章、护身符与身份标记。

## 7. 摄影

优先：

- 多多本人真实照片
- 真实旅途、人物、空间和海洋
- 自然光、不过度修图
- 能看见环境、动作和关系
- 允许失焦、颗粒和不完美

禁止：

- AI stock photo
- 过度磨皮
- 统一套高饱和旅游滤镜
- 把所有照片裁成同样卡片
- 无故事的商业大片

About 页可使用有机圆形、椭圆和不规则相框，但不能全站都用圆形照片。

## 8. 形态与布局

- 有机、不完全对称
- 层叠但不混乱
- 有留白，也有真实材料的密度
- 每页一种主空间语言
- 内容组件保持一致，不做组件展览
- 关键操作必须清楚，不让访客猜

## 9. 禁忌

- 蓝紫渐变（Logo 原蓝除外，但不做渐变背景）
- cyan neon 科技感（蓝绿色只能是海洋与互动，不是霓虹）
- glassmorphism
- 通用作品集卡片墙
- 纯黑大底
- 所有内容居中
- 大量圆角矩形 + 阴影
- bounce / elastic 动画
- 每个元素都漂浮
- 廉价椰树度假视觉
- 过度老地图滤镜
- 随机灵性符号
- 看起来像 AI 批量生成的 Landing Page
