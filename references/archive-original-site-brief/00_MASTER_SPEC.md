# DUODUO Personal Website — Master Specification

> 本文件是整个网站项目的最高级总规范。遇到冲突时，优先级依次为：多多最新明确决定 → 本文件 → 具体页面 Scene 文件 → 技术默认实践。

---

## 1. 项目定义

这是多多的中英文个人网站，也是一件能够证明她创造力、审美、真实经历与商业能力的作品。

它不是：

- 普通个人简历
- 传统往下滚动的作品集
- Notion 风知识库主页
- 纯旅行博客
- 纯泳衣电商
- 纯 AI 创业者主页
- 为了炫技而复杂难懂的数字装置

它应该让访问者感到：

> 我正在进入一个真实生活持续发生、作品持续形成、人与地方留下痕迹的多多世界。

网站本身必须同时完成四件事：

1. **形成记忆**：一眼看出这是多多，不是通用模板。
2. **解释她是谁**：把旅行、冲浪、青旅、内容、AI 和泳衣连接为同一个长期命题。
3. **证明她能做什么**：让商业合作方快速看到真实项目、角色和成果。
4. **让关系继续发生**：关注、合作、阅读、提问、使用工具或购买未来产品。

---

## 2. 核心命题与首页文案

### 主句

**A life made of waves, places, people and unfinished experiments.**  
**一个由浪、地方、人与未完成实验组成的人生。**

### 核心问题

**Exploring how to live freely while staying rooted in the real world.**  
**探索人如何既自由地活，又扎根在真实世界里。**

### 贯穿全站的暗线

**Freedom is not the absence of roots. It is learning to grow roots you can carry with you.**  
**自由不是没有根，而是把根长在可以随身携带的地方。**

这不是一句装饰性的哲学文案，而是所有页面的统一解释：

- STORIES：自由如何通过真实经历形成，而不是停留在想象。
- WORK：兴趣怎样落地为作品、价值、收入和长期资产。
- ABOUT：一个不断离开的人，如何逐渐找到能随身携带的根。
- SURF：自由如何通过身体、自然、纪律与持续练习获得结构。
- DUODUO OS：如何把个人经验转化为别人能理解和使用的工具。

## 3. 网站结构

首页海面上只有四座岛：

1. `STORIES｜故事`
2. `WORK｜作品`
3. `ABOUT｜关于`
4. `SURF｜冲浪`

此外必须有一个独立的 AI 功能页面：

5. `AI｜问多多`（页面内部名：`DUODUO OS｜多多系统`）

AI 页面不是第五座岛，但它是网站的第五个核心功能页面。它通过右上角固定入口、菜单或 Logo 附近的 AI 按钮进入。

推荐路径：

- `/` — Home / Living Ocean
- `/stories` — The Traveler’s Trunk
- `/work` — The Field Studio
- `/about` — The Life Voyage
- `/surf` — The Wave School
- `/ai` — AI / DUODUO OS 独立页面；可同时支持从全局菜单以 overlay 方式预览
- `/zh/...` 与 `/en/...`，或通过 locale state 实现中英文正文切换

首页四座岛必须简单易懂，只显示：

- STORIES 故事
- WORK 作品
- ABOUT 关于
- SURF 冲浪

诗意名称放在页面内部，不作为首次导航理解门槛。

## 4. 各页面定位

### HOME — The Living Ocean / 活着的海

真实海水动态与光感作为底层；手绘岛屿、航线、图腾和文字负责结构。四座岛是全站主导航。

### STORIES — The Traveler’s Trunk / 多多的旅行箱

展示：

- Duoduo Swimwear / Wear
- 旅途与人物 / Roads & People
- 生命材料与拾得物 / Found Objects

它不是旅行攻略，也不是商城，而是一只装着泳衣、地方、人物、照片、录音、票据和不完整记忆的旅行箱。

### WORK — The Field Studio / 多多的田野工作站

展示：

- Selected Work / 精选作品
- Thinking / 思考（来自公开 Notion Database）
- Media & Experiments / 内容与实验
- Collaborate / 合作

它是作品集、研究现场、内容入口与合作页面的统一体。

### ABOUT — The Life Voyage / 多多的人生航线

使用航线、照片与转折节点讲述多多如何走到今天。不是简历流水账。

### SURF — The Wave School / 多多的浪上学校

V1 展示冲浪故事、日志、地点、身体与生活设计；V2 才实现点击海浪进入笔记本教程。

### DUODUO OS — 多多系统

不是第五座岛，但必须是一个可独立访问、拥有固定 URL 的完整 AI 页面。它也可以从任意页面以菜单或 overlay 入口打开：

- Explore / 探索网站
- Ask Duoduo / 问多多
- Take Something / 带走一些东西
- Now / 此刻
- Contact / 联系

## 5. 视觉决定

### 官方 Logo

使用用户提供的第一组 `DUODUO WEAR` 图形与字标。不得用普通字体重打字标来代替。正式上线应替换为原始透明矢量文件。

### 首页风格：C1.5

- 第一眼：真实海洋与流动感。
- 第二眼：发现手绘岛屿、航线、图腾、文字与物件。
- 手绘是信息结构，不是装饰堆叠。
- 现代、简洁、可合作，但有个人世界观。

### 核心色

- Bright Ocean Teal / 亮蓝绿色高亮：`#00B4C5`
  - **首要用途是高亮文字**：标题中的关键词、重要短句、链接、选中导航、英文标签、数字与状态词。
  - 其次用于小面积交互反馈：下划线、文本选中、航线节点、focus ring、hover 标记和极少量按钮。
  - 不作为大面积页面背景，不把整段正文、整块卡片或整个网站染成亮蓝绿色。
- Warm Linen / 米白麻底：`#F1E9DA`
- Logo Blue / 身份蓝：`#2E27A8`
- Warm Ink / 暖墨红棕：`#5B2E2B`
- Deep Sea Ink / 深海墨绿：`#1F2E29`

Logo 蓝负责“我是谁”；蓝绿色负责“这个世界如何流动”；米色负责空间与呼吸；暖墨色负责叙述。

## 6. 设计气质

关键词：

- 海风感
- 真实
- 温暖米色
- 蓝绿色高亮
- 手作痕迹
- 编辑感
- 田野档案
- 原始图腾
- 野而温柔
- 原始而精致
- 自由而有骨头
- 不像 AI 模板

不得出现：

- 玻璃拟态
- 霓虹科技风
- 蓝紫渐变
- 通用 SaaS 卡片墙
- 廉价度假网站
- 过度老地图博物馆感
- 全站堆满装饰和无限动画
- 全部 section 同一种居中布局
- AI stock photo

## 7. 双语原则

导航与核心标题同时显示中英文：

- `STORIES｜故事`
- `WORK｜作品`
- `ABOUT｜关于`
- `SURF｜冲浪`

首页核心文案中英文同屏。

长正文不要逐段中英并排，使用语言切换；数据模型中保留 `*_zh` 与 `*_en` 字段。

英文负责国际感、标签与视觉节奏；中文负责真实叙述与细节。两种语言都必须自然，不做机械直译。

---

## 8. 内容真实性

网站只展示：

- 真正发生过的经历
- 已做过的项目与明确角色
- 正在进行、可标注状态的实验
- 多多愿意公开的文章、播客、视频和思考
- 对外可用的工具与 Prompt

不要：

- 把正在学的东西包装成专家服务
- 伪造项目结果和数据
- 公开私人心理记录、完整日记、关系细节或家庭冲突
- 让公开 AI 读取私人个人 Context
- 用励志成功人设覆盖未完成状态

## 9. 技术默认方案

推荐：

- React / Next.js + TypeScript
- 动效使用 CSS transform 与适量 motion library
- 海洋背景采用渐进增强：高性能动态视频或 Canvas/WebGL；低性能设备使用静态或轻动效替代
- Notion API 读取公开 Database，但页面必须使用本站组件重新渲染，不能直接嵌入原始 Notion 视觉
- AI 对话通过服务端 API + 公开知识库 RAG
- 所有私钥使用环境变量
- 支持 `prefers-reduced-motion`
- 支持键盘、触屏、屏幕阅读器
- 音频默认关闭

---

## 10. V1 验收定义

V1 必须是一个可发布、可联系、可展示真实作品的网站，而不是只有首页动画的概念 Demo。

必须具备：

- 完整四页
- 中英文导航与正文切换
- 动态海洋首页与四岛入口
- Stories 三个抽屉及至少若干真实内容条目
- Work 至少 4 个项目卡、Notion 内容接口或 mock 数据、合作入口
- About 7 个航线节点与照片占位
- Surf V1 内容
- DUODUO OS 的菜单、Now、Contact、Take Something
- AI Chat 可先用 mock，但接口结构必须完整；如有 API 则上线真实公开 AI
- 手机端重新组织，不是桌面缩小
- 基础 SEO、性能与无障碍

---

## 11. 重要实施原则

1. 先做清楚，再做惊艳。
2. 每页只有一种主空间语言，不做组件展览会。
3. 首页创意不能阻碍五秒理解。
4. 动效来自海、漂流、潮汐和痕迹，而不是按钮弹跳。
5. 不直接复制 Esther Design System 的代码、组件或模板；只借鉴“品牌 DNA + Scene + Checklist”的方法。
6. 没有真实内容时使用明确 placeholder，不伪造。
7. 正式文案、照片、联系方式和 Notion 数据库需在上线前由多多审核。
