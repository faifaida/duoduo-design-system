# V1 / V2 Scope｜一期与二期边界

## V1：必须上线的完整网站

### Home

- 动态海面或高质量 fallback
- 四岛导航
- 双语核心文案
- Logo、语言切换、DUODUO OS

### Stories

- 旅行箱场景
- WEAR / ROADS & PEOPLE / FOUND OBJECTS
- 至少 6–12 个内容条目或真实占位
- Duoduo Swimwear 简介

### Work

- Selected Work
- Thinking（Notion API 或 mock）
- Media & Experiments
- Collaborate
- 至少 4 个案例结构

### About

- 7 节点人生航线
- 照片占位与双语短文
- Now
- 核心结尾句

### Surf

- Surf Story
- Surf Log
- Places
- Notes
- V2 教程预告

### AI 独立页面 / DUODUO OS

- Explore
- Now
- Contact
- Take Something 3 个工具
- Ask Duoduo UI；真实 API 或高质量 mock

## V1 不做

- 完整泳衣商城
- 支付
- 会员系统
- 大规模用户社区
- 复杂 3D 游戏世界
- 自动读取全部私人知识库
- 完整冲浪教程系统
- 用户生成内容

## V1.5

- 接入真实公开 AI
- Notion 稳定自动更新
- 完整中英文文章
- 合作表单和邮件通知
- 内容 Analytics
- 更完整的 Stories 物件交互

## V2

### Surf 教程

全屏浪 → 点击知识点 → 进入笔记本教程。

### AI / DUODUO OS 工具库

更多可使用的 AI 页面、Prompt、模板与生成器。

### Duoduo Wear

- 产品目录
- 库存 / 购买或外部商城
- 设计过程与地点故事

### Living Ocean

- 更丰富的天气、时间或潮汐变化
- 用户航迹
- 隐藏彩蛋

## 迭代原则

- V1 先证明内容、结构和品牌成立。
- 只有真实使用数据证明某个功能有价值，才进入 V2。
- 不为“很酷”承担长期维护成本。


## V1 页面数量确认

V1 不是只有四个页面。页面结构为：

- Home
- Stories
- Work
- About
- Surf
- AI / DUODUO OS

其中 Stories / Work / About / Surf 是首页海面上的四座岛；AI 是独立功能页，通过固定按钮和菜单进入。
