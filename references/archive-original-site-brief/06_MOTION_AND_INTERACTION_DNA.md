# Motion & Interaction DNA｜动效与交互基因

## 动效的来源

动效必须来自自然与旅行经验，而不是通用 UI 特效。

### DRIFT｜漂流

岛屿、物件和照片有极轻微、不同步的位移。幅度小，避免晕眩。

### TIDE｜潮汐

内容进入与退出像潮水推进，不使用突然缩放和弹跳。

### WAVE｜波浪

页面转场可使用水平推进、轻微遮罩或水纹位移。

### FLOAT｜漂浮

只用于少量重要元素，不允许所有卡片悬浮。

### TRACE｜痕迹

航线、手写线和时间节点逐渐被画出。

### DISCOVER｜发现

Hover / Focus / Tap 后揭开标签、照片背面、纸张内容或项目细节。

## 首页海洋

目标是“活着的海”，不是全屏冲浪广告。

推荐渐进增强：

1. 高性能桌面：短循环真实海面视频或 WebGL / Canvas 水面。
2. 普通设备：优化视频 + 轻量叠加层。
3. 移动端：更短、更小的视频或 CSS / Canvas 轻动效。
4. `prefers-reduced-motion`：静态海面照片 + 航线轻微淡入。

要求：

- 无声音自动播放
- 如有环境音，必须由用户主动开启
- 海洋动作缓慢、可读
- 四座岛标签始终清楚
- 文案不会因浪纹失去对比

## Island Interaction

### Desktop

- Hover：岛屿略微靠近、航线点亮、显示一句说明
- Click：不是突然跳页，使用 400–800ms 的进入过渡
- Keyboard focus：效果与 hover 等价

### Mobile

- 不依赖 hover
- Tap 第一次显示简介，第二次或明确按钮进入
- 也可直接展示简介与入口按钮，避免双击困惑

## 页面内部

### Stories

行李箱打开、抽屉滑出、物件翻面。动作应具有重量和材质感，不像 App 卡片弹出。

### Work

动作更克制：筛选、展开案例、滚动阅读。不要因“工作站”概念影响效率。

### About

航线随滚动或拖动逐渐出现，照片节点可轻微浮动。移动端改为清楚纵向旅程。

### Surf

V1 以海浪视觉与日志为主。V2 点击浪型或动作后，进入纸质冲浪笔记本。

### DUODUO OS

功能反馈快速、清楚，减少场景化动效。终端打字效果只在首次开场或回答生成时使用，不能让用户等待整段文字逐字打完。

## 时间建议

- Hover：150–250ms
- 小界面切换：200–350ms
- 页面场景过渡：500–900ms
- 背景漂流周期：12–30s
- 航线绘制：800–1600ms

## 禁止

- bounce、elastic
- 无限旋转文本
- 高速视差
- 大幅 cursor 跟随
- 每个 section Scroll Reveal
- 按钮 hover 整块剧烈移动
- 自动播放声音
- 无法关闭的动画
- 动画导致内容延迟出现
