# Scene: STORIES — The Traveler’s Trunk｜多多的旅行箱

## 页面目的

让访问者通过物件、照片、地方和人物认识多多，而不是阅读一份自我介绍。

## 核心描述

**Objects, people and places collected along the way.**  
一只装着泳衣、旅途、人物与生命碎片的旅行箱。

## 结构：三个抽屉

### 1. WEAR｜穿戴

重点：Duoduo Swimwear / Duoduo Wear。

可展示：

- 为什么开始做泳衣
- 样品与第一次销售实验
- 斯里兰卡穿着与拍摄
- 面料、颜色和图案
- 设计草稿、失败样品与灵感物件
- 当前状态与未来系列

V1 不是商城。每件产品可以标注：

- Prototype / Sample / Available / Sold / In Development
- 样品 / 可售 / 已售 / 开发中

如需购买，可导向联系或外部销售页面。

### 2. ROADS & PEOPLE｜旅途与人

将地方和人物放在一起，因为多多旅行的核心不是打卡，而是进入陌生生活并与人交换。

内容类型：

- 一个地点 + 一个具体问题
- 一个受访者 + 一种生活选择
- 一段陆路旅程
- 青旅中的关系与文化观察
- 海边、城市、沙漠或村庄改变了什么判断
- 视频、录音、照片与短文

### 3. FOUND OBJECTS｜拾得物

尚未形成完整文章，但值得留下的生命材料：

- 票据
- 手写日记
- 录音片段
- 老照片
- 贝壳、绳结、地图
- 随手写下的一句话
- 旅行中捡到或交换的物件
- 未完成的故事线索

## 进入方式

页面首屏是一只打开或正在打开的旅行箱。

可点击物件映射：

- 泳衣 / 布料 → WEAR
- 护照 / 路线图 → ROADS & PEOPLE
- 相机 / 录音机 → ROADS & PEOPLE
- 信件 / 日记 / 贝壳 → FOUND OBJECTS

同时保留文字 Tab 或锚点，不能只靠猜物件。

## 内容卡片不做统一网格

根据内容使用：

- Polaroid / 照片
- 行李标签
- 票根
- 音频磁带
- 布料样本
- 折叠地图
- 纸页

但详情页的正文阅读布局必须统一、清楚。

## 单条 Story 数据

至少包含：

- title_zh / title_en
- type
- date
- location
- cover
- media
- short_note_zh / short_note_en
- full_story_zh / full_story_en
- related_project
- public_status

## 初始内容建议

- Duoduo Swimwear：从样品到斯里兰卡销售
- 一段中亚—土耳其陆路旅行
- 斯里兰卡青旅中的人物采访
- 一个改变你对“自由”理解的冲浪日
- 从青旅住客身上学到的一件事
- 旅行箱里的 8–12 个 Found Objects
