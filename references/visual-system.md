## 审美 DNA

一句话：**野而温柔、原始而精致、自由而有骨头、手作而有世界。**

让设计像被海风、旅行和真实项目使用过，而不是干净到没有生活。美不是装饰，而是身份表达、情绪调节、世界构建、品牌识别与对抗庸常。

## 正式颜色

当前线上源码是复刻时的最终数值：

| Token | Hex | 用途 |
|---|---|---|
| `--teal` | `#00B6C5` | 关键词、链接、状态、节点和少量互动 |
| `--teal-light` | `#1FCEDD` | 浪尖、高光、选中态，面积更小 |
| `--linen` | `#F1E9DA` | 主米色、纸张与浅色空间 |
| `--chalcedony` | `#E8DCC8` | 深一层的暖米色 |
| `--paper` | `#FAF6EE` | 亮纸面和内容页 |
| `--logo-blue` | `#2E27A8` | Logo 和身份印章，不作大背景 |
| `--brown` | `#8A6A4A` | 木、旧标签、次要文本 |
| `--red` | `#6B3A3A` | 暖墨红棕、少量 CTA 与叙述 |
| `--graphite` | `#25262B` | 浅色页面主文字 |
| `--night` | `#151A2E` | 夜海、About、OS 深色场景 |
| `--gold` | `#C99A3F` | 航线、星点、金属细节 |

早期说明中出现的 `#00B4C5` 是方向值；精确复刻使用当前源码的 `#00B6C5`。

把蓝绿色理解为一支高亮笔，不是一桶墙漆。浅色页面以米色和真实图片为主体；深色页面以夜海为主体；蓝绿色通常控制在视觉面积的 6–10% 以内。

## 字体与排版

当前线上字体栈：

```css
--serif-en: "Iowan Old Style", Baskerville, "Times New Roman", serif;
--serif-zh: "Songti SC", STSong, "Noto Serif CJK SC", serif;
--hand: "Kaiti SC", "Bradley Hand", cursive;
```

英文展示可使用 Fraunces；中文可使用 Noto Serif SC / 思源宋体。等宽字体只用于 DUODUO OS、状态和工具预览。

保持编辑感：展示标题大、正文安静、小标签真的小。中文 `letter-spacing: 0`。不要用 Inter、Roboto 或 Arial 作为主要视觉字体。手写体只作注释，不承载长正文。

## 材质与摄影

优先使用真实海面、真实旅行、真实人物、真实空间、项目材料与产品照片。允许颗粒、失焦、胶片边缘和不完美。

常用材质：米色纸、麻、绳、原木、皮革、贝壳、石头、陶、做旧金属、布料、票据和手写笔记。纹理透明度一般不超过 12%。

禁止 AI stock photo、过度磨皮、统一高饱和旅游滤镜和无故事商业大片。生成图只用于概念场景、纹理或无法实拍的编辑插画，并明确标记。

## 母题

从内容选择一个有意义母题：海浪、海平线、太阳、星芒、贝壳、海螺、航线、罗盘、绳结、地图、岩画、部落图腾、螺旋、山、植物、女性与动物的单线融合。

同一输出内重复一个母题形成识别，不随机撒灵性符号。母题通常使用单色线描、印章或材质轮廓，不做荧光贴纸。

## 形态与布局

- 使用有机、不完全对称、轻微错落和层叠。
- 保留足够留白，让真实材料承担密度。
- 每页只有一种主空间语言，同类内容保持组件一致。
- 形状可以像贝壳、岛屿、船体、纸页和航线；圆角不是默认答案。
- 深色场景与浅纸面形成节奏，但一页不要不断换主题。

## 禁忌

禁止蓝紫渐变、glassmorphism、neon/cyan 科技风、纯黑纯白主导、通用 SaaS 卡片墙、所有内容居中、卡片嵌套卡片、大量圆角阴影、bounce/elastic、无限旋转文字、廉价椰树度假风、过度老地图滤镜、随机图腾、默认 HTML 样式和通用 AI Landing Page。
