# 多多的统一审美（Unified Aesthetic）

> **本文件是 duoduo-design-system 的审美锚点。所有产出先过这一份，再查具体参考文件。**
> 它不是配色卡，是一套可执行的世界观。agent 动手前必须读完本节 + `identity-and-voice.md` + `visual-system.md`。

---

## 0. 一句话 DNA（写进骨子里）

**野而温柔、原始而精致、自由而有骨头、手作而有世界。**

设计要像被海风、旅行和真实项目使用过，不是干净到没有生活。美是身份表达、情绪调节、世界构建与对抗庸常，不是装饰。

---

## 1. 身份锚：谁在说话

- DUODUO 不是简历 / 旅行博客 / 泳衣商城 / AI 创业者模板。它是多多把**真实生活、旅行、冲浪、文旅空间、内容、服装实验、AI 个人公司**组织成一个公共世界的方法。
- 固定主句（可单选使用，不机械三连）：
  - *A life made of waves, places, people and unfinished experiments.* 一个由浪、地方、人与未完成实验组成的人生。
  - *Exploring how to live freely while staying rooted in the real world.* 探索人如何既自由地活，又扎根在真实世界里。
  - *Freedom is not the absence of roots. It is learning to grow roots you can carry with you.* 自由不是没有根，而是把根长在可以随身携带的地方。
- 语气：真实、直接、具体、好奇、轻微幽默。允许「正在形成 / 仍在测试 / 被现实推翻」。写地点、人物、动作、物件、选择——**不写抽象励志口号**。

## 2. 颜色（唯一真值表 + 用法上限）

| Token | Hex | 用途 | 面积上限 |
|---|---|---|---|
| `--teal` | `#00B6C5` | 关键词、链接、状态、节点、少量互动 | **≤10%** |
| `--teal-light` | `#1FCEDD` | 浪尖、高光、选中态 | **≤4%** |
| `--linen` | `#F1E9DA` | 主米色、纸张、浅色空间、海报底部色带 | 主体 |
| `--chalcedony` | `#E8DCC8` | 深一层暖米 | 辅 |
| `--paper` | `#FAF6EE` | 亮纸面、内容页 | 辅 |
| `--logo-blue` | `#2E27A8` | Logo / 身份印章 | 不作大背景 |
| `--brown` | `#8A6A4A` | 木、旧标签、次要文本 | 辅 |
| `--red` | `#6B3A3A` | 暖墨红棕、少量 CTA | 极少 |
| `--graphite` | `#25262B` | 浅色页面主文字 | 正文 |
| `--night` | `#151A2E` | 夜海、About、OS 深色场景 | 深场主体 |
| `--gold` | `#C99A3F` | 航线、星点、金属细节 | 极少 |

**铁律：**
- 把蓝绿色当成**一支高亮笔，不是一桶墙漆**。浅色页以米色 + 真实图片为主体；深色页以夜海为主体；蓝绿合计通常 **≤ 视觉面积 6–10%**。
- 主底偏**暖米色**；正文用暖墨或深海色；**不用纯黑纯白主导**。
- 早期方向值 `#00B4C5` 已废弃，精确复刻一律用 `#00B6C5`。

## 3. 字体（唯一栈 + 编辑感）

```css
--serif-en: "Iowan Old Style", Baskerville, "Times New Roman", serif;
--serif-zh: "Songti SC", STSong, "Noto Serif CJK SC", serif;
--hand: "Kaiti SC", "Bradley Hand", cursive;
```

- 英文展示可用 **Fraunces**；中文可用 **Noto Serif SC / 思源宋体**。
- 等宽字体**只**用于 DUODUO OS、状态与工具预览。
- 编辑感：展示标题大、正文安静、小标签真的小。中文 `letter-spacing: 0`。
- **禁用** Inter / Roboto / Arial 作为主要视觉字体。手写体只作注释，不承载长正文。

---

## 4. 材质与摄影

- 优先**真实**海面、旅行、人物、空间、项目材料、产品照片。允许颗粒、失焦、胶片边缘、不完美。
- 常用材质：米色纸、麻、绳、原木、皮革、贝壳、石头、陶、做旧金属、布料、票据、手写笔记。纹理透明度一般 ≤ 12%。
- **禁止** AI stock photo、过度磨皮、统一高饱和旅游滤镜、无故事商业大片。生成图只用于概念场景 / 纹理 / 无法实拍的编辑插画，且必须明确标记。

---

## 5. 母题（选一个有意义的，重复成识别）

从内容选一个母题重复出现：海浪、海平线、太阳、星芒、贝壳、海螺、航线、罗盘、绳结、地图、岩画、部落图腾、螺旋、山、植物、女性与动物的单线融合。

- 同一输出内**重复一个母题**形成识别，不随机撒灵性符号。
- 母题用单色线描 / 印章 / 材质轮廓，不做荧光贴纸。
- 一页只有**一种主空间语言**（活着的海 / 旅行箱 / 田野工作站 / 浪上学校 / 人生航线 / DUODUO OS），不把所有母题堆进同一页。

---

## 6. 布局与形态

- 有机、不完全对称、轻微错落、层叠。保留足够留白让真实材料承担密度。
- 每页一个主句、一个视觉焦点、一个明确动作。
- 形状可像贝壳 / 岛屿 / 船体 / 纸页 / 航线；圆角不是默认答案。
- 深色场景与浅纸面形成节奏，但一页不要不断换主题。
- 移动端**重新编排**，不缩小桌面构图。

---

## 7. 产品 / 海报视觉铁律（品牌视觉的硬规则）

> 这条之前是缺口：资产进了 `assets/wear-product/`，但规则没写进来。现在定为指令。

**每张 DUODUO WEAR / 品牌海报必须遵守：**

1. **底部 logo lockup 不可省**：图片正下方沿边放一条 `linen #F1E9DA` 色带，**铺满整个底部米色区域，无色差衔接**（不悬空、不描边、不另加底色块）。
2. **logo 与文案并排、整体缩小**：`duoduo-wear-full-logo` 居中，品牌字与辅助文案并排于其旁/下，整体占比小、克制，不抢主体视觉。
3. **主体优先**：上方是产品 / 平铺 / 场景真实图；底部色带只是身份落款。
4. **画幅与字号安全区**：已确认社媒/招募海报 **768×1074** 为基准；文字保留边距安全区，在目标尺寸下回看清晰度、对比度、裁切。
5. **去 AI 水印**：生成图交付前必须裁底 + 渐变（主图→ night #151A2E；详情→ linen #F1E9DA）。
6. **只用正式 full logo**，不用旧裁切残片、不另造字标。

参考成品：`assets/wear-product/DUODUO_WEAR_v2_recruitment_poster_logo_768x1074.png`

## 8. 不可破的红线（non-negotiables）

- 使用真实 `DUODUO` symbol 与当前站点 lockup 规范；不使用旧裁切残片或另造字标。
- 当前网站章节顺序固定：`Stories → Work → Surf & Wear → About`；首页保持海洋世界 + 清楚入口，不做通用 Landing Page。
- `#00B6C5 / #1FCEDD` 只作重点与互动高亮，不大面积铺底。
- 主底暖米，正文暖墨/深海，不用纯黑纯白主导。
- **禁止**：蓝紫渐变、glassmorphism、neon/cyan 科技风、纯黑纯白主导、通用 SaaS 卡片墙、所有内容居中、卡片套卡片、大量圆角阴影、bounce/elastic、无限旋转文字、廉价椰树度假风、过度老地图滤镜、随机图腾、默认 HTML 样式、通用 AI Landing Page、AI stock photo。
- 不伪造项目结果，不把「正在学习」包装成专家服务。
- 不公开私人日记、心理咨询、关系、家庭、财务、密码、Token 或完整个人 Context。
- 不复制受限的 Esther Design System 代码；只沿用「Skill + 场景 + 组件 + Checklist」的方法。

## 9. 给 agent 的执行清单（动手前过一遍）

1. 读完本文件 + `identity-and-voice.md` + `visual-system.md`。
2. 确认用途 / 受众 / 平台 / 画幅 / 核心信息；能从仓库与上下文确定的不反复问。
3. 选 **一个母题、一个主句、一个视觉焦点**。
4. 从正式资产起步：网站用 `assets/faifaida-reference/`；公众号用 `assets/templates/wechat-article.html`；图文/海报用 `social-card.html` 或 `brand-poster.html`；品牌标志用 `assets/brand/current/`。
5. 应用视觉系统：批准 token、全衬线编辑感、真实照片、可触摸材质、一个母题。蓝绿当高亮笔。
6. 海报/产品图套用第 7 节铁律。
7. 跑 `references/quality-gates.md`；图片在目标尺寸回看文字/边距/对比/裁切。
8. 交付可用文件 + 说明采用的正式素材、保留的历史参考、未解决的内容缺口、验证结果。
