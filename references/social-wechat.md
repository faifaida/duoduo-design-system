# Social, WeChat and Poster Design

## 通用原则

把网页世界转换为编辑视觉，不直接截网页。每张图只表达一个观点或一个故事节点。优先使用真实照片、项目材料、海面、纸、布、票据与 Logo；再用线描母题组织层级。

## 公众号

从 `assets/templates/wechat-article.html` 开始。使用全内联样式，正文宽度和字号适配微信编辑器。

建议结构：Logo/栏目签、标题、引言、真实主图、2–4 个小节、一个 Pull Quote、项目或人物资料、结尾行动。正文中文 16–17px、行高约 1.8；小标题 21–26px；图片不要被圆角卡片统一处理。

浅米色可用于题头和分隔，但微信正文背景以稳定可读为先。蓝绿色只高亮关键词、编号和链接。不要使用复杂定位、外链字体、脚本、视频背景或依赖 CSS 变量。

## 社媒卡片

默认 3:4，使用 1080x1440；封面安全边距至少 72px。系列图保持 Logo、页码和边距固定，布局按内容变化。

封面使用一个强主句 + 一个真实视觉。内页可用：大照片注释、地图与路线、项目档案、三问结构、前后判断、物件故事、单句留白。避免每页相同标题+三张卡。

## 海报与封面

优先做“一个物件或人物 + 一个地点或问题 + 一个品牌印记”。品牌海报可更野，公众号封面要更清楚。小尺寸预览中仍应认出标题、人物/对象和 DUODUO 身份。

## 图片生成

生成图片时描述真实材料和可观察场景：自然光、暖米纸、真实海水、原木、麻布、贝壳、旅行票据、手绘航线、低饱和胶片颗粒。指定构图和留字区域。

不要要求“boho aesthetic”后让模型自由发挥；写清楚主体、地点、材质、色彩比例、视角和禁止项。禁止 generic resort、商业 stock photo、霓虹、过度梦幻、蓝紫渐变和不可辨认的假文字。

生成图只能当概念或背景时，在资产说明中标记 `generated-reference`。人物、真实项目、产品和地点需要真实照片或明确的概念标注。
