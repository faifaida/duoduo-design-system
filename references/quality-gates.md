# Quality Gates

## P0 必须全过

- [ ] 使用真实 DUODUO symbol 与当前站点 lockup 规范，没有使用旧裁切残片或另造字标。
- [ ] 颜色来自正式 token；没有蓝紫渐变、neon、glassmorphism 或纯黑纯白主导。
- [ ] 蓝绿色只作高亮、状态和小面积互动，没有铺满整页或整组卡片。
- [ ] 主体使用真实内容与批准素材，没有 AI stock photo 或伪造结果。
- [ ] 每个输出有一个主空间语言和一个有意义母题，不是图腾随机拼贴。
- [ ] 没有通用 SaaS 卡片墙、卡片嵌套卡片或所有内容居中。
- [ ] 没有浏览器默认 blockquote、table、list、input 和 button 样式。
- [ ] 中文字距正常；文字在桌面与手机不溢出、不重叠、不遮挡。
- [ ] 网站支持鼠标、键盘、触屏和 reduced motion；不依赖 hover 才能使用。
- [ ] 移动端重新编排，不是缩小桌面画面。
- [ ] 当前网站章节保持 `Stories -> Work -> Surf & Wear -> About`。
- [ ] 所有输入、提交、返回、关闭、loading、empty 和 error 状态可用。
- [ ] 没有密码、Token、API Key、私人 Context 或未批准个人资料。

## P1 应当完成

- [ ] 真实照片、项目材料和品牌母题形成统一叙事。
- [ ] 字号层级有明显对比，但正文仍舒适。
- [ ] 深色场景与浅纸面形成节奏，不频繁换主题。
- [ ] 英文自然，中文具体，项目角色和状态准确。
- [ ] 图片 alt、焦点样式、颜色对比和语义结构完整。
- [ ] 动效来自漂流、潮汐、波浪、痕迹或发现，且不拖慢阅读。
- [ ] 对外文件包含正确尺寸、格式和可追溯来源。

## P2 加分

- [ ] 一个真正有记忆点、与内容相关的互动细节。
- [ ] 同一母题在页眉、章节和结尾形成弱重复。
- [ ] 真实物件有背面、出处、时间或地点说明。
- [ ] 分享图在缩略图中仍能认出 DUODUO。

## 最后六问

1. 这像多多，还是像任何 AI 都会做的模板？
2. 这个视觉能摸到什么材质？
3. 主体是真实的人、物、项目和问题吗？
4. 商业合作方能快速找到角色、结果与联系吗？
5. 动效和装饰全部关闭后，内容仍成立吗？
6. 有没有一个部分显得“AI 很努力地做设计”？有则删减或重做。
