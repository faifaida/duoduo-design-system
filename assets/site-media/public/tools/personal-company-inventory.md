# Personal Company Inventory｜个人公司自我盘点

Use this prompt with an AI, or answer it by hand.

## 1. Assets I already carry｜我已经随身携带的资产

- Which experiences have changed my judgment?
- Which skills can I repeatedly use in the real world?
- Which relationships, places and resources can I responsibly activate?
- Which unfinished materials could become stories, products or services?

## 2. Freedom and roots｜自由与根

- What kind of freedom am I trying to protect?
- What must keep accumulating even when I move?
- Which responsibilities make my life more real rather than less free?

## 3. The next real test｜下一个真实测试

- What is the smallest experiment I can run in 14 days?
- What evidence would change my current belief?
- What will I stop doing to make room for this test?

Finish with: one decision, one experiment and one public artifact.
